# Bright Roots Kids

A colorful, responsive home for **Bright Roots Kids**—an early-learning children’s channel centered on joyful Black representation, African history, and African American stories.

## Included

- Original responsive homepage
- Preschool-friendly visual design
- Featured episode concepts
- Learning pillars for ages 2–5
- Accessible navigation and reduced-motion support
- No build tools or dependencies required

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

In this repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Before launch

Add the official YouTube channel URL when it is available. The featured episode buttons show a “coming soon” message until real videos are added.
